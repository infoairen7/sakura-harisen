# 実装メモ — サクラの定時退社！ぶっとびハリセン（テストプレイ版）

## 起動方法（ローカル）

```
python3 build.py https://infoairen7.github.io/sakura-harisen/   # src/ と public/ → dist/
cd dist && python3 -m http.server 8765
# ブラウザで http://localhost:8765/
```

`file://` で直接開くと設定JSONを読めないため、必ずHTTPサーバー経由で開いてください。
build.py の引数は、結果画像と投稿文に入るゲームのURLです。

## 構成

| パス | 内容 |
|---|---|
| `src/game.js` | ゲーム本体（Canvas 2D・素のJavaScript。ライブラリなし） |
| `src/style.css` / `src/body.html` | 画面・UI |
| `build.py` | 1ファイルのHTMLへまとめ、`dist/` を作る |
| `public/` | 配信用の画像・マスク・設定JSON（企画パックの設定JSONをそのまま使用） |
| `dist/` | 公開しているサイト |
| `tests/` | Playwrightによる自動テスト・画面撮影 |

### 画像の扱い
- 原本PNGは変更していません。配信用に同寸のWebP派生を作成（背景は非可逆q90、アトラスは非可逆q92＋アルファ無劣化、アルファ12未満の不可視ハローのみ除去）。
- `assets/sakura_costume_mask.png`：衣装色替え用マスク（髪・肌・白シャツ・タイツを除外）。
- `assets/boss_shirt_mask.png`：上司のシャツ領域。飛行中の泥・すすをここだけに重ねる。
- 特典 `sakura_bromide.png` は**配信物に含めていません**（読み込みもしません）。

## 実装済み
- タイトル／オープニング4カット（初回のみ・スキップ可）／コース選択／装備確認／READY→RUN→SWING→FLIGHT→LAND→RESULT
- 判定：`e = |(tap+0.10) − 予測接触時刻|`、PERFECT〜GRAZE（上限を含む）、MISS（無入力・早すぎ・遅すぎ）
- 入力：pointerdown／Space・Enter、キーリピート・多重タップ無視、「走り出す」直後0.3秒の二度押し無視
- 飛距離：解析式で第一接地点のみ記録（30/45/60/120/144fpsで誤差0）
- 全10コース・5ワールド背景・2コース目の色オーバーレイと粒子量差
- 育成：XP閾値・同時複数レベルアップ・強化上限・強化費用・初回クリアボーナス（クリア記録と同時保存）
- 衣装10段階のマスク色替え（動作中）＋図鑑は完成立ち絵、上司シャツ10段階（着地後の立ち絵・コース紹介）
- ストレス計算とセリフ、結果画像1200×630生成、画像保存（公開ページでは保存機能、通常ブラウザではダウンロード）、OS共有（対応端末のみ）、XのWeb Intent
- セーブ：localStorage（schemaVersion付き、破損時は確認して初期化）＋公開ページではクラウドの個人領域にも同期
- 一時停止（タブ離脱で自動停止・3秒カウントダウン復帰）、効果音（Web Audio合成）・ミュート・揺れ軽減
- 縦／横／PCのレイアウト切替、素材チェック画面（実寸・矩形・読み込み結果）、テスト用ツール

## 仕様からの調整点
- 縦画面のゲーム窓は640×最大600（ほぼ正方形の横長）。16:9だと縦持ちで余白が大きすぎたため。
- 距離表示は小数1桁の切り捨て（129.96mが「130.0m」と表示されて未クリアになる混乱を避けるため）。判定は丸め前の値。
- スプライトは原寸から段階縮小（ミップ）してから描画。高解像度素材を最近傍で4〜5分の1にするとちらつくため。
- 走り・スイング・喜び・上司の飛行と着地は、8ポーズの間をクロスフェードでつなぎ、伸び縮み・残像・ハリセンの軌跡を重ねて動かしている（ポーズそのものを増やすには追加作画が必要）。

## 自動テスト結果（Playwright / Chromium）
- フレームレート独立：同じ入力時刻で30/45/60/120/144fpsの距離差 0.000000m
- 判定境界：40.0ms=PERFECT, 40.1ms=GREAT, 85.0ms=GREAT, 85.1ms=GOOD, 140.0ms=GOOD, 140.1ms=GRAZE, 210.0ms=GRAZE, 210.1ms=MISS
- 推奨装備PERFECTの距離：設定JSONから計算した値が `references/balance_check.json` と全10コース一致
- 練習モード（判定1.5倍・報酬なし）、無入力MISS（XP8/coin10）、早すぎMISS、多重タップ無視
- 初回クリアボーナスは1回のみ、リロード後も進行が残る、壊れたセーブは確認後に初期化
- 全PERFECT＋強化の自動プレイで25回目に全10コースクリア、装備Lv10・PLAYER Lv5に到達
- 飛行中のタブ離脱で停止・時刻凍結、復帰後も距離は同一
